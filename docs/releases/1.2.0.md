SLink 1.2.0 保留原生 C# / WPF 架构，更新主控按钮、应用图标和安装界面，并修复连接完成后的短暂误报。

### 下载

- **Windows 安装包**：`SLink-1.2.0-Setup-x64.exe`
- 安装包校验：`SLink-1.2.0-Setup-x64.exe.sha256`
- 所有主要附件校验：`SHA256SUMS.txt`
- 项目源码：`SLink-1.2.0-source.zip`
- MSYS2 运行库对应源码：`msys2-runtime-aa532e7bbf59a3ec1e29e13c9e8515d545cb2e16.tar.gz`

需要 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、支持移动热点的 Wi-Fi 网卡和管理员权限。安装包未签名，请核对仓库来源与 SHA-256。

### 更新

- 居中的圆形图标主控按钮，明确区分等待、检测、连接、暂停、关闭与异常状态，提供对应提示和无障碍名称。
- 分阶段显示代理、网卡和热点状态，完成后显示短标题；改进交互反馈、旋转外环与完成动画。
- 修复关闭 Windows 装饰动画后忙碌外环不转，以及标题栏空白区域无法拖动的问题。
- 网络操作改用独立 JSON 结果文件，避免转发子进程继承输出句柄造成虚假超时；复用启动时已验证的链路结果，避免紧接着重复检测代理。会话身份变化仍会重新检查，真实错误继续显示。
- 新应用图标与简体中文精简安装流程，延续原 AppId、设置及会话记录，保留升级和卸载前的网络清理。
- 拆分界面状态模型、动画、辅助进程与网络桥接模块；按核心、状态与 WPF 交互整理测试并更新开发文档。

### 验证与限制

本地通过 C#/WPF 与 PowerShell 自动化回归、应用编译和安装包编译。发布工作流从版本标签重新执行测试并构建附件，源码与校验文件一起提供。

自动化测试覆盖动画、按钮动作、标题栏命中、异步连接完成、结果传输、健康判断及模拟网络清理；不修改实际网络。本次没有执行真实热点、音响播放及安装/升级/卸载的端到端测试，硬件和驱动兼容性仍需实际环境验证。

使用与排错见仓库 README 和 `docs/troubleshooting.md`。SLink 源码采用 GPL-3.0，第三方组件按各自许可证分发。
