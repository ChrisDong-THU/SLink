SLink 首次开源发布：把 Windows 上的本机 SOCKS5 代理共享到 Wi-Fi 热点，面向 JBL 等音响与 Qobuz Connect 的使用场景。

### 下载

- **Windows 安装包**：`SLink-1.1.0-Setup-x64.exe`
- 安装包校验：`SLink-1.1.0-Setup-x64.exe.sha256`
- 所有主要附件的校验：`SHA256SUMS.txt`
- 项目源码：`SLink-1.1.0-source.zip`
- 随包 MSYS2 运行库对应源码：`msys2-runtime-aa532e7bbf59a3ec1e29e13c9e8515d545cb2e16.tar.gz`

需要 Windows 10 2004+ / Windows 11 x64、.NET Framework 4.8、支持移动热点的 Wi-Fi 网卡和管理员权限。代理由用户自行提供；使用 Clash 时关闭其 TUN。安装包未签名，请从本仓库下载并核对 SHA-256。

### 包含内容

- 原生 C# / WPF 界面、独立 HEV / Wintun 网卡与热点启停。
- 设备列表、代理端口检测、诊断导出、音响地址变化提示。
- 有界热点修复、资源归属校验、会话恢复与退出清理。
- 整理后的源码与文档，固定依赖及其许可证，自动构建和发布流程。

### 验证与限制

发布流程执行 C# / WPF 和 PowerShell 回归检查，并从标签源码编译安装包。测试覆盖逻辑、界面预览、探测与清理的模拟场景；不代表所有硬件上的实际热点、Qobuz 播放或安装升级均已验证。本次整理未执行真实网络和安装升级的端到端测试。

界面目前为简体中文，仅提供 Windows x64 安装包。「热点就绪」表示探测通过，不代表音响已建立播放会话。

使用方法与排错见仓库 README 和 `docs/troubleshooting.md`。SLink 源码采用 GPL-3.0，第三方组件按各自许可证分发。
