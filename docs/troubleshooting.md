# 使用与排错

## 启动前

确认 Windows 版本和 .NET Framework 符合要求，Wi-Fi 支持移动热点，本机 SOCKS5 代理可访问 Qobuz。使用 Clash 时关闭其 TUN；不需要修改 Clash 配置或打开远程代理访问。

## 常见问题

| 现象 | 排查步骤 |
| --- | --- |
| 无法连接本机代理 | 启动代理客户端；核对 SOCKS5 / mixed 端口；在 SLink 中检测或手动填写。仅 HTTP 代理端口不适用。 |
| 代理可用但热点启动失败 | 检查 Windows「设置 → 网络和 Internet → 移动热点」、Wi-Fi 驱动和上网连接；确认没有其他工具占用共享。 |
| 热点就绪但音响不可见 | 确认手机和音响均连接显示的热点；检查音响固件和 Qobuz Connect 支持；设备地址变化后使用 Qobuz 菜单中的重新发现。 |
| JBL 连接过蓝牙后无法播放 | 关闭控制手机蓝牙并重启音响后重试。SLink 无法读取或解除音响蓝牙占用。 |
| 能发现音响但播放失败 | 先确认代理节点、Qobuz 账号与服务本身可用；热点就绪并不代表已建立播放会话。 |
| 窗口关闭后程序仍在运行 | 这是托盘模式。右键托盘图标选择退出，等待清理完成。 |
| 升级或卸载提示清理未完成 | 回到 SLink 停止连接再重试，必要时重新打开应用执行恢复。不要直接删除会话记录或批量结束代理进程。 |

## 诊断

打开界面的诊断入口，查看错误和最近检查结果，按需导出。提交 Issue 时提供 SLink 版本、Windows 构建号、Wi-Fi 网卡/驱动、代理客户端、复现步骤和期望结果。导出内容及 `%LOCALAPPDATA%\SLink` 的文件应在检查和脱敏后分享，不要直接上传整个数据目录。

## 卸载

先停止连接，再从 Windows 已安装的应用中卸载。安装器会协调退出并清理会话；用户设置保留，便于重装。只有在确认连接已停止、没有待恢复会话且不再需要设置时，才考虑自行删除本地数据目录。
